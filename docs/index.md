It was first drafted with AI in January 2026, then checked page by page in October 2026 against [spec v1.19](https://spec.matrix.org/v1.19/), [Synapse 1.163](https://element-hq.github.io/synapse/latest/) and the current release of every project it describes. ## What is Matrix?

Matrix is an open standard for decentralised, real-time communication. Anyone can run a homeserver, and homeservers federate: users on different servers share rooms, much as people on different email providers can write to each other. Rooms can be end-to-end encrypted.
